# Polyglot Heaven — Sites-native rebuild

Independent Sites production foundation for Polyglot Heaven. It contains no Lovable runtime, tagger, URL, or deployment dependency.

## Included

- Enchanted Development Hall with intelligent practice prescriptions
- TSI five-stage progression
- Language profile cards
- Nine-phase parts-of-speech Training Camp
- Expanded pattern-family catalogue
- Yan-san Japanese Basic Speaker Studio
- Browser speech synthesis and recognition
- Three.js Heaven Universe foundation
- LinkedIn-oriented badges and certificate interface
- Responsive desktop and mobile UI

## Run

```bash
npm install
npm run dev
npm run build
```

Configure the Sites project root as `polyglot-heaven-sites` and publish `dist`.

Coverage percentages refer to estimated functional coverage within the defined curriculum. CEFR estimates, pronunciation, vocabulary, pattern mastery, and game completion remain separate measurements.
